# network-penetration-testing-lab

## Overview
A practical network penetration testing exercise conducted
against an intentionally vulnerable virtual machine in a
controlled lab environment.

## Objectives
- Perform network reconnaissance and port scanning.
- Identify running services and potential vulnerabilities.
- Research known vulnerabilities and associated CVEs.
- Conduct controlled exploitation attempts.
- Assess password security using password auditing tools.
- Document findings and remediation recommendations.

## Tools Used
- Kali Linux
- Nmap
- Metasploit Framework
- John the Ripper
- zip2john

## Methodology
1. Network discovery and reconnaissance.
2. Port scanning and service enumeration.
3. Vulnerability identification and research.
4. Controlled exploitation attempts.
5. Password hash extraction and auditing.
6. Documentation and remediation.

## Key Vulnerabilities Investigated
- CVE-2010-2075 – UnrealIRCd Backdoor
- CVE-2017-12149 – JBoss HTTP Invoker Deserialization

## Disclaimer
All testing was conducted within an authorised,
controlled virtual lab environment for educational purposes.
